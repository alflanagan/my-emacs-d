1.2. Clipboard Tweaks

More optimizations from the blog post by Bozhidar Batsov.

1.2.1. Keep Clipbard Contents

Here’s a scenario: you copy a URL from your browser, switch to Emacs, kill a line with C-k, and then try to yank the URL you copied earlier with C-y. Gone. The kill replaced it on the clipboard.

This setting makes Emacs save the existing clipboard content into the kill ring before overwriting it: 

(setopt save-interprogram-paste-before-kill t)

1.2.2. De-Duplicate Kill Ring

(setopt kill-do-not-save-duplicates t)

1.2.3. Fix find-file-at-point

The ffap function is a.k.a. find-file-at-point, and I only use it for files. So it's a real problem when it tries to interpret the filenama as a URL, so I turn it off. 

(setopt ffap-machine-p-known 'reject)

1.3. Easy Customization

Set up separate file for use by emacs customization.

I prefer to set customization options in the use-package declaration for each package, but on-the-fly or local-only customizations will go to this file. 

(defun get-config-file (filename)
          "Returns FILENAME absolute path in the user's my_emacs directory."
          (expand-file-name filename
                            (expand-file-name "my_emacs/"
                                              user-emacs-directory)))

;; custom-file is built-in global variable.
(setq custom-file (get-config-file "custom.el"))
(load custom-file 'no-error 'no-message)

We need to add the melpa package source to package-archives. 

(setopt
 package-archives
 '(("gnu" . "https://elpa.gnu.org/packages/") ("nongnu" . "https://elpa.nongnu.org/nongnu/")
   ("melpa" . "https://melpa.org/packages/")))

1.4. Load Path

Emacs 31 adds my_emacs/lisp to load-path through user-lisp-directory (set in early-config.org). Older versions need it added explicitly. 

(when (< emacs-major-version 31)
  (add-to-list 'load-path (expand-file-name "my_emacs/lisp" user-emacs-directory))
  (add-to-list
   'load-path (expand-file-name "my_emacs/lisp/org-contrib/lisp" user-emacs-directory)))

1.5. Secrets File

This local file is for global variables with values which should not be checked in with source control, such as passwords and API keys.

Mine defines a function define-secret-customizations which calls setopt to set customization options that should be secret. 

(if (require 'my-secrets nil 'noerror)
    (when (fboundp 'define-secret-customizations)
      (define-secret-customizations))
  (display-warning 'my-config "my-secrets.el not found on load-path" :warning))

1.6. Uniquify

Uniquify is a part of emacs which is not loaded by default, but it can be ~require~d to change the way buffers are named when editing different files with the same name. From the source file:

Emacs's traditional method for making buffer names unique adds <2>, <3>, etc. to the end of (all but one of) the buffers. This file replaces that behavior, for buffers visiting files and Dired buffers, with a uniquification that adds parts of the file name until the buffer names are unique. 

(require 'uniquify)
(setopt uniquify-buffer-name-style 'post-forward-angle-brackets)

1.7. Customizing Emacs Itself

We can use use-package to configure emacs itself as a 'pseudo-package'. 

(use-package
 emacs

 :bind
 (("M-/" . #'hippie-expand)
  ("C-x C-b" . #'ibuffer)
  ("C-s" . #'isearch-forward-regexp)
  ("C-r" . #'isearch-backward-regexp)
  ("C-M-s" . #'isearch-forward)
  ("C-M-r" . #'isearch-backward)
  ("C-x M-r" . #'remember)

  ("C-x M-R" .
   (lambda ()
     (interactive)
     (let ((current-prefix-arg '(4)))
       (call-interactively #'remember))))
  ("s-q" . nil)
  ;; runs save-buffers-kill-emacs by default, but too easy to hit by accident
  )

 :config
 (global-auto-revert-mode)
 (when window-system
   (tool-bar-mode -1))
 (blink-cursor-mode -1)
 (when (equal system-type 'darwin)
   (setopt trash-directory "~/.Trash"))

 ;; set coding systems used to Unicode standard
 (set-terminal-coding-system 'utf-8)
 (set-keyboard-coding-system 'utf-8)
 (prefer-coding-system 'utf-8)

 (ido-mode t)
 (ido-everywhere t)

 ;; be careful with this: it can conflict with version control hooks such as
 ;; precommit (see alse ~kill-buffer-delete-auto-save-files~
 (auto-save-visited-mode t)

 (column-number-mode t) ;; displays current column in mode line
 (setq-default indent-tabs-mode nil)

 (save-place-mode t)
 (show-paren-mode t)
 (transient-mark-mode t) ;; visually highlight selected region

 (when (>= emacs-major-version 30)
   (minibuffer-regexp-mode 1) ;; syntax highlighting for writing regexps
   (setopt project-mode-line t)) ;; show clickable project name in mode line

 :custom
 (ido-big-directories '("node_modules" "\\.?venv"))
 (ido-cannot-complete-command #'ido-completion-help)
 (ido-ignore-directories '("\\`CVS/" "\\`\\.\\./" "\\`\\./" "\\`__pycache__/"))
 (ido-use-filename-at-point nil)
 (ido-use-url-at-point t)
 (ido-use-virtual-buffers 'auto)
 ;; auto-save options
 (kill-buffer-delete-auto-save-files t)
 (delete-by-moving-to-trash t) ;; use system trash can for deleted files
 (apropos-do-all t)
 ;; put file backups in single directory, not in same directory with '~'
 ;; appended.
 (backup-directory-alist `(("." . ,(concat user-emacs-directory "backups"))))
 (use-package-compute-statistics t) ;; get useful startup timings with M-x use-package-report

 ;; old libraries are creating temporary buffers without the lexical-binding
 ;; tag. Since I don't need that warning, clean up *Warnings* a bit by silencing
 ;; it

 (warning-suppress-types '((files missing-lexbind-cookie)))
 ;; log warnings to *Warnings*, but only pop up the buffer for errors
 (warning-minimum-level :error)

 (server-log t)
 ;; use value of `truncate_lines' even in windows narrower than frame
 (truncate-partial-width-windows nil)
 (use-file-dialog nil)
 (visible-bell (not (equal system-type 'darwin))) ;;bad on mac
 ;; don't show package in menu if higher-priority package is found
 (package-menu-hide-low-priority t)

 ;; Python setup: assume mise manages uv, and uv creates .venv in each project.
 ;; Prepend .venv/bin to exec-path so python3 resolves to the project venv.
 (python-shell-exec-path '("./.venv/bin"))
 (python-interpreter "python3")
 (python-shell-interpreter "python3")
 (echo-keystrokes 0.1) ;; reduce lag in echo keystroke to sc28reen
 (fill-column 80)
 ;; use as much syntax highlighting as possible, by default
 (font-lock-maximum-decoration t)
 (inhibit-startup-message t) ;; turn off Emacs splash screen
 (initial-scratch-message nil)
 (mouse-yank-at-point t)
 (save-interprogram-paste-before-kill t)
 (save-place-file (expand-file-name "places" user-emacs-directory))
 (select-enable-clipboard t) ;; integrate emacs with system clipboard
 (select-enable-primary t)
 (selection-coding-system 'utf-8)

 ;; don't automatically double space after sentence end -- obsolete style
 (sentence-end-double-space nil)

 ;; I use the [Commonmark](httsp://commonmark.org) executable ~cmark-gfm~ for
 ;; rendering markdown files, with GitHub-flavored extensions. So I need to
 ;; tell markdown-ts-mode.
 (markdown-command
  "cmark-gfm -e footnotes -e table -e strikethrough -e tasklist --table-prefer-style-attributes --github-pre-lang --unsafe")

 :hook (prog-mode . display-line-numbers-mode)
 ;; Treat CamelCaseSubWords as separate words in every programming mode.
 (prog-mode . subword-mode))

1.9.4. Ido and amx

There are (at least) three major emacs packages to enable auto-completion: "ivy", "company", and "ido". Ivy is full-featured and includes "counsel", which modifies emacs commands to use ivy. However, it looks not to be actively maintained, and I've come to prefer "ido". It's builtin to Emacs, which is convenient.

Install ido-completing-read+, an undeclared dependency of ido.

This package replaces stock emacs completion with ido completion wherever it is possible to do so without breaking things (i.e. what you were probably hoping for when you set ido-everywhere to t). 

(use-package ido-completing-read+
  :config
    (ido-ubiquitous-mode 1))

The "amx" package leverages "ido" to add features to the Emacs execute-extended-command function (M-x). 

(use-package amx
    :config (amx-mode 1))

This package automatically strips extra whitespace from the end of lines. 

(use-package whitespace-cleanup-mode :config (global-whitespace-cleanup-mode 1))

1.9.6. Treemacs

Set up treemacs, the directory tree sidebar. See treemacs repo for all the gory details. 

(use-package
 treemacs
 :defer nil

 :init
 (require 'cua-base)
 (with-eval-after-load 'winum
   (define-key winum-keymap (kbd "M-0") #'treemacs-select-window))
 :config
 (when treemacs-python-executable
   (treemacs-git-mode 'extended)
   (treemacs-git-commit-diff-mode t)
   (treemacs-hide-gitignored-files-mode t))
 ;; treemacs-git-commit-diff fires async callbacks for all workspace projects,
 ;; including ones not currently visible in the buffer.  When the callback
 ;; tries to annotate a path whose project node doesn't exist in the buffer,
 ;; treemacs-project->position receives nil and crashes.  Guard against that.
 (with-eval-after-load 'treemacs-git-commit-diff-mode
   (advice-add
    'treemacs-apply-single-annotation
    :before-while (lambda (path) (treemacs-is-path path :in-workspace))))
 (treemacs-project-follow-mode 1)
 (treemacs-filewatch-mode 1)
 ;; follow mode makes it difficult to find file that are not on-screen
 (treemacs-follow-mode -1)
 ;; init.el loads this file inside `save-window-excursion', which would close a
 ;; sidebar opened now; open it once startup is finished instead.
 (add-hook 'emacs-startup-hook #'treemacs-start-on-boot)

 :custom
 (treemacs-is-never-other-window t)
 (treemacs-follow-after-init nil)

 :bind
 ;; M-0 intentionally omitted here; scoped to winum-keymap in :init above
 ;; to avoid shadowing digit-argument globally.
 ;; C-x t 1 → tab-close-other (Emacs 27+); use C-x t o instead.
 ;; C-x t d → dired-other-tab  (Emacs 28+); use C-x t D instead.
 ("C-x t o" . treemacs-delete-other-windows)
 ("C-x t t" . treemacs)
 ("C-x t D" . treemacs-select-directory)
 ("C-x t B" . treemacs-bookmark)
 ("C-x t C-t" . treemacs-find-file)
 ("C-x t M-t" . treemacs-find-tag))

1.9.8. Flycheck

Flycheck is a modern on-the-fly syntax checking extension for GNU Emacs, intended as replacement for the older Flymake extension which is part of GNU Emacs.

flycheck-aspell integrates the spelling checker aspell into flycheck. You need to have aspell installed. flycheck-pos-tip shows the flycheck error message in a small popup window, so you don't have to look at the message. flycheck-status-emoji shows the current flycheck status as a face emoji on the mode line (other editors call this the status line), cute but also saves mode line space. 

(use-package
 flycheck
 :hook (after-init . global-flycheck-mode)
 :pin "nongnu"
 :config (add-to-list 'flycheck-checkers 'org-lint)
 ;; errcheck and go build are causing errors in flycheck
 :custom
 (flycheck-disabled-checkers '(go-errcheck go-build))
 ;; *scratch* has no file, so Emacs 30+ never trusts it and Flycheck can't check
 ;; it; skip lisp-interaction-mode instead of showing a "no checker" message.
 (flycheck-global-modes '(not lisp-interaction-mode)))
(use-package flycheck-pos-tip :after flycheck :config (flycheck-pos-tip-mode))

1.9.10. Zap Up To Char

In Emac's standard keybindings, the command `zap-to-char` is bound to key M-z (alt-Z on PC, option-Z on Mac). However I find the `zap-up-to-char` command to be more useful, so I'm rebinding the key. 

(bind-key "M-z" #'zap-up-to-char)

1.9.11. Web Mode

web-mode adds support for templating languages to html-mode. It supports over 20 templating languages, including Jinja. There's also a mode called jinja2-mode, however it is not up-to-date with the latest Jinja versions. web-mode is much better. 

;; see https://web-mode.org/!!
(use-package
 web-mode
 :defer t
 :mode
 (("\\.phtml\\'" . web-mode)
  ("\\.php\\'" . web-mode)
  ("\\.tpl\\'" . web-mode)
  ("\\.[agj]sp\\'" . web-mode)
  ("\\.as[cp]x\\'" . web-mode)
  ("\\.mustache\\'" . web-mode)
  ("\\.html\\'" . web-mode)
  ("\\.djhtml\\'" . web-mode))
 :custom
 (web-mode-enable-comment-interpolation t)
 (web-mode-enable-engine-detection t)
 ; this assumes we're always using django
 (web-mode-engines-alist '(("django" . "\\.html\\'"))))

1.9.15. Language Server Protocol

Not long ago, an editor had to have custom handling written for each language it "knew". This led to a lot of duplication of effort, and bad editor implementations.

Now there are 2 major protocols that can be provided by language authors to communicate information about a language to an editor. The Language Server Protocol allows the editor to connect to an external server process, which provides information about the language.

The Tree-Sitter protocol provides a set of shared libraries which the editor dynamically links to, and that run in the editor's process.

Emacs now supports both methods.

This sets up lsp-mode to integrate with the LSP, and then we use a package to integrate the information into the treemacs sidebar also.

LSP Mode Docs 

(use-package
 lsp-mode
 :defer t
 :commands lsp
 ;; these are the LSP servers I have right now. Customize this for your setup!
 :hook
 ((sh-mode bash-ts-mode dockerfile-ts-mode sql-mode typescript-ts-mode) . 'lsp-deferred)
 :custom (lsp-enable-snippet nil) (lsp-warn-no-matched-clients nil))

(use-package lsp-treemacs :after (lsp-mode treemacs))

1.9.17. CMake

Support for CMake build files and CMake-based C/C++ projects.

(use-package cmake-mode)

(use-package cmake-project :after cmake-mode)
